# ALMAR ARB LIVE

Мобильное веб-приложение для поиска математических букмекерских вилок по реальным котировкам The Odds API.

## Запуск

После включения GitHub Pages сайт будет доступен по адресу:
https://almar-analytics.github.io/almar-arb-live/

Для поиска реальных котировок пользователь вводит собственный ключ The Odds API непосредственно в приложении. API-ключ не включён в исходный код и не сохраняется в localStorage.

## Включение GitHub Pages

Repository Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

**Важно:** репозиторий сейчас приватный. На бесплатном плане GitHub Pages обычно требует публичный репозиторий; проверьте доступный тариф и видимость в Settings → General → Danger Zone → Change repository visibility.

## Возможности

- Поиск реальных событий и котировок (без демонстрационных матчей).
- Сопоставление рынка 1X2, тоталов и фор.
- Калькулятор сумм ставок в тенге.
- Фильтры по турнирам, доходности и свежести линий.
- Установка на главный экран через браузер после публикации.

## Ограничения

Не гарантирует реальную доходность: коэффициенты могут измениться до размещения ставок. Букмекеры и рынки доступны в зависимости от подписки API, прав доступа, страны и времени. Приложение не делает ставки.
